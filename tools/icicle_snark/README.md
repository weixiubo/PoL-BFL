# ICICLE-Snark Build

This directory contains the dependency lock used to build the ICICLE-Snark
worker for BN254 Groth16 proof generation. The worker consumes Circom
`.zkey` and `.wtns` files and produces standard proof and public-signal
outputs.

`Cargo.lock` fixes the Rust dependency graph associated with the selected
upstream revision. The build script installs the CUDA worker under
`.tools/icicle-snark/`:

```bash
bash scripts/build_icicle_snark.sh
```

Proofs generated by the worker can be checked independently with the
Rapidsnark verifier.
